# RePlate — Asset List

## 1. Required Product Assets
- `logo.svg` or simple text logo
- `app_icon.png` (optional)
- `historical_meals.csv`
- `README.md`
- `requirements.txt`

## 2. Required Demo Assets
- Screenshot of prediction result.
- Screenshot of measurement/analytics result.
- Final pitch deck / presentation.
- One architecture diagram.
- One simple problem-to-solution diagram.

## 3. Dataset Assets
- Synthetic raw dataset CSV.
- Optional generated cleaned dataset if preprocessing requires it.

## 4. Documentation Assets
- PRD.md
- TRD.md
- UX.md
- UI.md
- DATA.md
- MODEL.md
- SPIRIT.md
- ASSET-LIST.md
- TEST-PLAN.md
- DEMO.md
- PITCH.md

## 5. Asset Naming Rules
Use lowercase filenames with hyphens where practical.

Examples:
- `prediction-screen.png`
- `architecture-diagram.png`
- `synthetic-meals.csv`

## 6. Do Not Add
- Stock photos that do not support the product story.
- Decorative AI imagery.
- Unused icons.
- Fake partner logos.
- Screenshots of functionality that does not exist in the live demo.
